# Principios de Programación 1

Repositorio utilizado para organizar y publicar los ejercicios y soluciones desarrollados durante las clases de Principios de Programación 1.

## Estructura del repositorio

- `ejercicios/` → Contiene los ejercicios desarrollados durante el curso.
- `README.md` → Contiene información general sobre el repositorio.

## Ejercicios

### Beca estudiantil

Programa desarrollado en Python que determina si un estudiante puede obtener una beca según:

- Promedio académico.
- Porcentaje de asistencia.
- Participación en un programa de apoyo institucional.

El programa utiliza estructuras condicionales (`if` y `else`) y operadores lógicos (`and` y `or`).
